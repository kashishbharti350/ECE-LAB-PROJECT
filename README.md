ECE Lab Pro ⚡An interactive engineering workbench and logic simulation platform built specifically for Electronics and Communication Engineering (ECE) students. ECE Lab Pro bridges the gap between theoretical coursework and practical application by providing intuitive, visual, and highly interactive tools for circuit analysis and digital logic design.Designed with a clean, modern interface, this application serves as both a daily study companion and a teaching aid for beginner programmers and engineering students.🛠️ Tech StackThis project is built with a modern, high-performance web development stack:Framework: Svelte + ViteLanguage: TypeScript / JavaScriptCanvas Engine: @xyflow/svelte (SvelteFlow)Icons: lucide-svelteStyling: Custom CSS with dynamic Light/Dark mode theming and 3D UI elements✨ Core Modules & Features1. Electronics ToolkitA comprehensive suite of day-to-day calculators with built-in unit conversions and correct engineering formulas.Ohm’s Law & Power Calculator: Instantly calculate Voltage, Current, Resistance, and Power.Resistor Color Code Decoder: Interactive 4-band and 5-band color code reader for physical lab work.RC Circuit Analyzer: Calculate time constants ($\tau = R \times C$) and cutoff frequencies ($f_c = \frac{1}{2\pi RC}$) with automatic validation and responsive UI feedback.2. LogicLab Pro SimulatorAn advanced, drag-and-drop node canvas for building and visualizing complex digital logic circuits.Interactive Canvas: Infinite panning, zooming, and mini-map navigation.Custom Engineering Nodes: Custom-built Svelte components for inputs (0/1) and logic gates (AND, OR, NAND, etc.) featuring premium 3D aesthetics, neon glowing states, and intuitive connection handles.Dynamic Routing: Animated, smooth-step edges connecting logic gates.
